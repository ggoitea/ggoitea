# Cómo trabajo

No considero que una tecnología sea una solución por sí misma.

Me interesa elegir la herramienta adecuada para el problema, manteniendo un equilibrio entre **simplicidad, mantenibilidad, rendimiento y capacidad de evolución**.

Utilizo herramientas modernas —incluyendo IA, automatización, contenedores, CI/CD y cloud— como parte del proceso de desarrollo, pero intento que la tecnología esté al servicio del problema y no al revés.

También tengo experiencia trabajando con sistemas existentes: entender código legacy, encontrar cuellos de botella, refactorizar progresivamente y mejorar una plataforma sin necesidad de reescribirla desde cero.
